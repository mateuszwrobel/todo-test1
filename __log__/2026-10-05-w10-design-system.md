Three parts landed on the W9 styling layer with behavior frozen (ids, htmx wiring, routes, status codes, rendered wording untouched): the token split, named component classes consumed by the templates, and the `#c-*` component examples in the `/__components` gallery. Zero wiring change in `cmd/todo`; archspec stays at 4 modules.

**Token inventory (`ui/static/tokens.css`, one `:root` block, served at its own static route).** The brief's inventory — `--color-primary`, `--color-primary-hover`, `--color-text`, `--color-text-muted`, `--color-danger`, `--color-danger-bg`, `--color-border`, `--color-divider`, `--color-bg-page`, `--color-bg-panel`, `--color-focus-ring`, `--space-1..6`, `--radius-sm/md/lg`, `--shadow-card`, `--text-sm/base/lg/xl`, `--font-stack` — plus seven color values and one shadow the W9 stylesheet already used that the inventory names don't cover: `--color-on-primary` (primary-button text), `--color-border-field` (input borders, retry), `--color-surface-secondary` + `--color-surface-secondary-hover` (secondary-button surfaces — value-equal to `--color-border`, named so the button background isn't a border reference), `--color-danger-ink` + `--color-danger-border` (banner text/border, distinct from `--color-danger`), `--color-bg-sunken` (failure panel), and `--shadow-soft` (gallery sections). Naming them was forced by the two hard rules together — pixel-identical output and no raw hex outside `tokens.css`: rounding any of those values to an inventory token would move pixels, and leaving them would leave hex in `style.css`. Space tokens cover the 4–18px rhythm actually used; mockup-exact one-offs (card paddings, 48px gaps, 14px edit-error text) stay literal px with comments — pixel anchors, not colors. `tokens.css` is linked **before** `style.css` in both page shells; the order is commented in the shells and the handler and pinned by a unit test, as is the hex-free invariant itself.

**Class map (templates swap class attributes only).** `.btn` on every button with `--primary` (Add, Save) / `--secondary` (Edit, Delete, Cancel) and `:disabled` styling replacing the bare `button`/attribute selectors; `.input` on both text fields; `.checkbox` on row checkboxes; `.row` + `.row--done` on list rows (`data-state` stays the frozen attribute, the class mirrors it); `.error-text` on create and edit refusals (the row-attached one keeps `.edit-error` too — the frozen w4 e2e names that class as the refusal anchor); `.banner` replaces `.missing-todo` on `#missing-todo-banner`; `.hint` replaces `.create-hint`; `.empty-state` + `.panel` on the stated panels (`.panel` also on `#todo-list`); `.heading` on both `h1`s. Role hooks the frozen e2e selectors address (`.title`, `.save`, `.delete`, `.edit`, `.edit-form`, `.editing`) stay in every class list.
